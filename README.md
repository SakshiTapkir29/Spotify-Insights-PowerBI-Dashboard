# Spotify-Insights-PowerBI-Dashboard

🎧 Spotify Insights Dashboard – Power BI
An interactive Power BI dashboard built using the Spotify Top 50 dataset to analyze song popularity, artist performance, album types, and explicit vs non-explicit trends.
This project was created with the help of ChatGPT for data summarization, requirement structuring, and documentation support.

📌 Project Overview
This dashboard provides a concise visual summary of Spotify’s Top 50 tracks.
It highlights KPIs, popularity trends, artist-level insights, album-type distribution, and explicit vs non-explicit comparisons.
ChatGPT was used to support idea generation, business requirement writing, and documentation clarity.

🎯 Objectives
Track total songs, total artists & average popularity
Compare explicit vs non-explicit songs
Identify top artists and top songs
Analyze monthly & yearly popularity trends
Explore album type and duration patterns
Use ChatGPT to enhance project explanation and structure

🛠 Tools Used
Power BI Desktop
Power Query
DAX Measures
Excel/CSV Dataset
ChatGPT (for documentation & analysis)
